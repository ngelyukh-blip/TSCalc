# TSCalc — правила проекта

Общаться с пользователем на русском языке, объяснять результаты через элементы сцены, количества и документы.

## Область работы

Прочитать `docs/DECISIONS.md`, `docs/PLAN.md`, `docs/BACKLOG.md` и `docs/TEAM.md` перед работой. Текущие инструкции пользователя имеют приоритет над историческими записями Claude и TFCalc.

TSCalc считает по готовой раскладке; TFCalc остаётся отдельным плагином AutoCAD. Чертёж всегда в миллиметрах. Не выводить масштаб из INSUNITS, если он равен нулю: согласованный масштаб — мм.

Приоритет основания: явное ручное назначение в TSCalc, затем явно заданная зона DWG, затем семантика элемента сцены. Без зон круг, кольцо и подъёмно-опускные площадки — металл, всё остальное — бетон. При неоднозначной принадлежности запросить решение, не угадывать.

## Разделение ролей

Руководитель ведёт задания и вопросы пользователя. Разработчик реализует изменения. Проверяющий независимо проверяет формулы, код, геометрию и документы. Не выдавать самопроверку разработчика за независимую проверку. При отсутствии отдельного выполнения роли указывать это в отчёте.

Не запускать фоновых агентов, отдельные чаты или автоматизации только из-за наличия этих инструкций: использовать доступный и разрешённый пользователем механизм выполнения.

## Изменения

Исходные DWG и старый Excel читать без сохранения изменений. Испытания с изменениями — на копиях. Не менять сторонний TFCalc в рамках TSCalc. Реализацию вести по согласованным этапам; обычные обратимые действия внутри задания не требуют повторных подтверждений.

Проверять реальные сценарии и границы расчёта. Не принимать отсутствие ошибок в сохранённых значениях Excel за проверку пересчёта формул. Не подбирать произвольно конструктивные нормы и коммерческие параметры.

## GitHub

Единственный согласованный удалённый репозиторий TSCalc: `https://github.com/ngelyukh-blip/TSCalc`.

Руководителю поручено контролировать коммиты и отправку законченных изменений в этот репозиторий. Перед первым изменением проверить ветку, существующее содержимое и AGENTS.md репозитория. При доступном origin убедиться, что он указывает именно на TSCalc; не подменять другой remote.

Делать содержательные коммиты по завершённым заданиям. В описании фиксировать изменение, проверки и ограничения. Не использовать force-push, не переписывать чужую историю, не включать чужие незакоммиченные изменения. Соблюдать существующий порядок веток и PR. При его отсутствии вести новую работу в ветке `codex/project-setup`; слияние согласовать по результату проверки.

Не коммитить пароли, токены, пользовательский архив, исходные коммерческие документы, локальные временные файлы или необезличенные тестовые данные. Указание коммитить проект не разрешает автоматически публиковать все исходные материалы.

Коммит, push и независимая проверка — разные статусы. Сообщать фактический результат; при недоступном GitHub сохранить подготовленные файлы и записать причину блокировки.
