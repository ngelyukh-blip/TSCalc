# Согласованные решения

Дата: 11.11.2026. Источник — текущие указания пользователя в TSCalc.

| ID | Решение |
|---|---|
| D-001 | TSCalc читает готовую раскладку DWG. Создание и изменение раскладки не входят в первую версию. |
| D-002 | TFCalc — отдельный плагин AutoCAD для раскладки щитов, лаг, плинтуса и дубовой рейки. |
| D-003 | Размеры всех исходных чертежей заданы в миллиметрах независимо от INSUNITS. |
| D-004 | При отсутствии зон поворотный круг, кольцо и подъёмно-опускные площадки крепятся к металлоконструкции; остальные участки — к бетону. |
| D-005 | Явно заданные зоны имеют приоритет над назначением по умолчанию. В TSCalc необходимо показывать источник назначения и поддержать ручную корректировку. |
| D-006 | Материалы выбираются из базы на отдельном листе Excel и группируются по типам. |
| D-007 | Шаг и комплект крепежа должны настраиваться по зонам и узлам основания. |
| D-008 | В команде нужны руководитель, разработчик и независимый проверяющий/тестировщик. Руководитель собирает вопросы к пользователю. |
| D-009 | Порядок выполнения проекта согласован. Сначала аудит и роли, затем данные, импорт, материалы, расчёт, стоимость, проверка и документация. |
| D-010 | Руководитель должен обеспечивать коммиты проекта в https://github.com/ngelyukh-blip/TSCalc. |
| D-011 | Руководитель собирает актуальные PDF по проектированию, монтажу и приёмке щитового планшета сцены и планшета из палубного бруса; проверяет по ним информацию и передаёт пользователю обоснованные замечания. |
| D-012 | Нормативные документы хранятся в рабочей папке проекта; локальные пути в GitHub не публикуются. |

## Предложения, ещё не утверждённые как стандарт

- Зоны задавать замкнутыми полилиниями на отдельном слое, а штриховку использовать для отображения. Точный формат имени и атрибутов предстоит согласовать после анализа DWG.
- Отделить расчётное ядро от импорта AutoCAD и формирования Excel. Язык и интерфейс ещё не выбраны.
- Сохранять версию чертежа, базы материалов и правил расчёта в каждом выпуске калькуляции.

## Непринятые решения

Состав стоимости (монтаж, доставка, накладные, прибыль, НДС), источники цен и подтверждённые нормы расхода ещё не определены. Не принимать отсутствие ответа за согласование.


## Уточнения пользователя от 11.11.2026 после подготовки проекта

| ID | Решение |
|---|---|
| D-013 | Для текущего аудита используется доступная локальная копия архива. |
| D-014 | Текущий объём: аудит архива и Excel, распределение заданий и подготовка нормативно-технической базы. Логику работы с DWG отложить до отдельного продолжения. |
| D-015 | База щитов содержит только три типоразмера: 2400×1200×60, 2400×1200×70 и 2000×1000×60 мм. Каждый доступен из ангарской сосны или лиственницы. Геометрические типы монтажных элементов не определяют ассортимент закупаемых щитов. |
| D-016 | Исторические шаги крепления, расходы и цены из архивных проектов не становятся нормами нового калькулятора без подтверждения применимости. |
| D-017 | Испытания пересчёта Excel считать выполненными только при фактическом запуске вычислительного движка. Статический анализ формул и сохранённых значений учитывать отдельно. |
