## Подтверждённые ограничения старого Excel

| Наблюдение | Требование к TSCalc |
|---|---|
| Ввод поддерживает десять типов щитов, а позиции заказа используют только первые три | Все введённые типы должны попадать в спецификацию |
| Диапазон лаг ограничен пятьюстами строками и четырьмя сечениями | Не обрезать данные молча при превышении лимита |
| Точки крепления оцениваются по общей длине, шагу и количеству кусков | Проверять крепление отдельных отрезков, отступы, стыки и границы зон |
| Пересечения ярусов оцениваются через шаг | Сопоставлять с фактическими пересечениями готовой раскладки |
| Плинтус и рейка получаются из общих периметров | Читать фактически проложенные элементы с исключениями |
| Нормы и коэффициенты имеют пометки об уточнении | Не считать их утверждёнными нормативами |
| Нет отдельной базы материалов и расчёта стоимости | Разделить справочники, потребность и калькуляцию |

Сохранить принцип «чистое количество → один запас → закупочное округление». Уточнить уровень объединения одинаковых материалов до округления упаковок.

## DWG

Прочитаны вхождения динамических блоков, атрибуты и параметры. Встречаются анонимные определения *U...: использовать EffectiveName и данные элемента. Общий счётчик базы чертежа нельзя принимать за ведомость материалов модели.

Щиты имеют атрибуты марки, ширины, длины, обозначения и площади. Лаги — ширины, длины, высоты, плотности, массы и наименования. Размеры фигурного щита не заменяют его действительную площадь. Толщину щита подтвердить отдельно. Геометрическая сверка атрибутов и обрезки ещё не выполнена.

## Наследие TFCalc

Есть команды распознавания сцены, раскладки, плинтуса, рейки и экспорта лаг в Excel. По описанию TFCalc рейка строится по обеим сторонам швов: не удваивать повторно уже нарисованные линии.

История содержит случаи дублирования щитов при повторных запусках и перепутанных окружностей круга/кольца. Они включены в приёмочные сценарии TSCalc. Исторические результаты другого файла не являются проверкой нового DWG.
