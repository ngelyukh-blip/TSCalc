# TSCalc — команда проекта

Пакет предоставляет три роли: `tscalc-manager`, `tscalc-developer`, `tscalc-reviewer`.

Вызвать роль можно поручением «Руководитель TSCalc…», «Разработчик TSCalc…» или «Проверяющий TSCalc…». Инструкции не создают отдельные фоновые процессы автоматически и не предоставляют доступа к дискам или GitHub сами по себе.

Перед работой роли читают общие правила и актуальные документы локального проекта. Встроенные материалы — начальная версия от 11.11.2026; более поздние явные решения пользователя и актуальные документы проекта имеют приоритет.

Основная папка: `F:\МАНН Работа\TSCalc`. Репозиторий: https://github.com/ngelyukh-blip/TSCalc

Реальные исходные чертежи, архив, цены и история Claude в пакет не входят. Использовать доступные текущей сессии инструменты AutoCAD, файловой системы и GitHub. Если необходимый инструмент недоступен, назвать конкретную блокировку и продолжить независимую часть задания.
