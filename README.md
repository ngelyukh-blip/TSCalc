# TSCalc

Калькулятор материалов, калькуляций и спецификаций элементов сцены по готовой раскладке DWG.

TFCalc — отдельный плагин AutoCAD, который выполняет раскладку. TSCalc читает её результат и не меняет алгоритмы TFCalc.

## Статус на 11.11.2026

Согласованы порядок выполнения проекта, единицы чертежа и правила назначения основания по умолчанию. Подготовлены роли руководителя, разработчика и проверяющего в пакете `plugins/tscalc-team`; роли доступны текущей сессии. Подключение GitHub подтверждено.

Приложение-калькулятор ещё не реализовано. Первая задача разработки — чтение и сверка ведомости существующих элементов DWG.

## Расположение

- Основная папка пользователя: `F:\МАНН Работа\TSCalc`.
- Репозиторий: https://github.com/ngelyukh-blip/TSCalc
- Исходные DWG, калькуляции, коммерческие цены и архив проектов не включать в репозиторий автоматически. Перед передачей реальных данных учитывать доступность репозитория; для тестов использовать обезличенные примеры.
- Текущая подготовка выполнена в рабочей папке текущей сессии; перенос в основную папку и доступ к удалённому репозиторию требуют фактической проверки, а не предположения по путям.
