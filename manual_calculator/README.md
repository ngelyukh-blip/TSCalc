# TSCalc Manual 0.2.1

Excel-калькулятор с ручными исходными данными. Обработка DWG подключается после завершения калькулятора.

## Возможности

- Ручные зоны, лаги, щиты, дубовая рейка и плинтус.
- Выбор материала из базы с автоматической единицей измерения.
- Позиционные площади верха, низа, торцов и полной поверхности щитов; продольных граней, торцов и полной поверхности лаг.
- Автоматические расходы по составу прежнего шаблона, отдельные запас, закупка, цены и спецификация.
- Контроль ввода и геометрических условий крепежа.

Каталог щитов: 2400×1200×60, 2400×1200×70 и 2000×1000×60 мм. Материал: ангарская сосна или лиственница.

## Сборка

Требуются Python и openpyxl 3.1 или новее.

```sh
python manual_calculator/build_manual.py template.xlsx
```

Входной файл — совместимый прежний шаблон с листами «Параметры» и «Расчёт» и ожидаемыми именованными диапазонами. Он предоставляется отдельно и не публикуется с кодом. Произвольная книга Excel вместо шаблона не поддерживается. При отсутствии аргумента используется template.xlsx в корне проекта.

Новая книга TSCalc_Manual_v0.2.1.xlsx сохраняется в корне проекта. Исходный шаблон не изменяется.

## Проверки и ограничения

Выполнены статическое ревью формул, независимая контрольная арифметика и визуальная проверка ключевых листов. Нативный пересчёт в Microsoft Excel не подтверждён; книга настроена на пересчёт при открытии.

Параметры прежнего шаблона остаются настраиваемыми исходными данными, требующими подтверждения применимости. Раскрой заготовок не выполняется. Монтаж, доставка, накладные, прибыль и отдельное начисление НДС требуют согласования.

Нестандартные дополнительные комплекты на листе «Узлы» в колонках G:L ещё требуют доработки проверки пар «материал / расход»; этот путь не принят. Для текущей версии использовать стандартный автоматический расчёт.

Публичный код не содержит локальных путей, исходных коммерческих книг и внутренних отчётов. Версия остаётся в подготовительной ветке; слияние в основную ветку не выполнено.

## Исправление 0.2.1

Опирание верхней лаги на дерево отделено от основания зоны пола. Верхний деревянный ярус разрешён над бетонной, металлической и виброизолированной зоной без повторного учёта площади. Проверки нижних узлов сохранены.

Для щитов и линейных элементов зона необязательна: пустое поле означает сводные данные по объекту, без создания искусственной площадной зоны.

Регрессионная сверка по исходным вводам и независимой арифметике: все строки лаг учитываются, 31 из 31 материальных позиций соответствует эталону. Нативный пересчёт Microsoft Excel не выполнен; этот результат не обозначает испытание в Excel.
